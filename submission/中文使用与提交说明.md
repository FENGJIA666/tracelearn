# TraceLearn 使用与提交说明

TraceLearn 是一套本地运行的 AI 学习工作区，首个完整课程为大学数据库基础。它把“诊断题 → 原文证据 → 针对性反馈 → 迁移题 → 学习记录”连接起来。核心差异是让使用者核对依据并再次应用概念。

## 在这台 Mac 上打开

双击项目目录内的 `Start-TraceLearn.command`。依赖和两个模型已安装，正常使用不需要 API 密钥，也不需要付费服务。程序地址为 `http://127.0.0.1:4317`。初次进入其他设备时需要 Node.js、Ollama，并运行 `npm run setup`；模型下载约 3.2 GB，不包含在源码压缩包内。

## 三分钟演示

1. 进入 **SQL NULL**。题目问工资 100、200、NULL 中，哪些会通过 `salary <> 100`。
2. 选择 **200 and NULL**，自信程度选 **Very sure**，点击检查。这是演示故意选错，不是实际学生实验。
3. 阅读反馈，再点击 **null-where**。原文解释：WHERE 只保留 TRUE，NULL 比较得到 UNKNOWN。
4. 打开迁移题，选择 **price <> 10 OR price IS NULL**，检查正确结果。
5. 点击 **Explore this reasoning with local AI**，再点 **Ask the source**，查看真实本地模型解释和原文引用。材料不足或模型校验失败会明确显示，不提供伪造成功结果。
6. 在 **Notebook** 导出 Markdown 学习报告。刷新后记录保留在本机 SQLite 数据库。

右上角可切换中文。内置课程原文有中文译文；题目保留英语技术措辞。自己的材料可导入文本 PDF、Markdown 或 TXT，最多 10 MB、50 PDF 页。扫描 PDF 不支持 OCR。`examples/revision-notes.md` 是可以直接导入的原创示例。

## 材料在哪里

- `Devpost-Story.md`：可直接复制的英文正文。
- `TraceLearn-Technical-Report.pdf`：英文技术与实际评测报告。
- `AI-DISCLOSURE.md`：Codex 和本地 Qwen 模型贡献披露。
- `00-cover.png`：3:2 封面。
- `01` 至 `06` 开头的 PNG：六张最终真实浏览器截图。
- `../evaluation/`：冻结数据、模型版本、最终运行记录、指标和非独立语义复核。
- `../evidence/`：软件测试、离线推理、界面验收记录。

## 数据与限制

你的导入材料、生成题和答题记录在项目 `.local/tracelearn.sqlite` 中；交付包不含这个个人运行数据库。无账号、社交功能或云端同步。引用校验保证引文能在材料中找到，不能证明模型解释语义一定正确。自定义材料出题明确标记 AI 生成，采用可按原文逐字核对的填空题，检查原文记忆，不作为概念迁移测验；未经过独立教师审核。
