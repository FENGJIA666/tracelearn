# TraceLearn 使用与提交说明

TraceLearn 把“先预测 → 核对原文 → 改条件做实验 → 独立完成迁移题 → 导出记录”连成完整学习流程。首个课程是大学数据库基础。v1.2 的核心新增是可编辑的 **Counterexample Lab（概念实验）**：结果由确定性程序计算，可以逐步核对。

## 先体验便携版

下载 [TraceLearn-Portable.html](https://github.com/FENGJIA666/tracelearn/releases/download/v1.2.0/TraceLearn-Portable.html)，文件不到0.5 MB，包含20道原创题、原文、SQL与候选键实验、复习建议和导出，不需要Node、模型或API密钥。

浏览器工具禁止自动访问 `file://`，因此直接双击HTML的路径未实测；已验证的方式是通过本机静态网页打开。在解压项目目录运行：

```sh
python3 -m http.server 4329 --bind 127.0.0.1 --directory submission
```

然后打开 <http://127.0.0.1:4329/TraceLearn-Portable.html>。这只是本机预览，不是公开部署。

## 核心体验

1. 用页面中的 **Quick tour** 进入 **Predict**。SQL NULL题中故意选择 **200 and NULL**、**Very sure**，即可体验错题反馈。点击 **null-where** 核对原文。这是软件演示操作，不是真实学生实验。
2. 进入 **Experiment / Lab**，保留100、200、NULL三行，预测哪些行能通过 `value <> 100`，再点击 **Run & check prediction**。表格逐行列出TRUE、FALSE或UNKNOWN，以及保留/排除结果。
3. 把条件改成 `value <> target OR value IS NULL`，重新预测。也可以改数据、添加行、改为NOT IN列表，检验原来的理解在哪些条件下不成立。
4. 点击 **Try a transfer question**，独立完成迁移题；即使以前答过，这个入口也打开新的未作答状态。
5. 在Lab导出 **TraceLearn-lab-record.md**：保存输入、预测、材料哈希与重新计算的结果。Notebook另行导出题目和AI问答学习记录；Lab预测不计入题目正确率。
6. 切换 **Keys & closure**。在第一个关系中比较A、AD与ABD：A推不出D，AD是候选键，ABD中的B可删除。每一步依赖和最小性检查都会显示。

Lab不调用AI，不支持任意SQL，也不自动证明所有范式。它提供四种SQL条件和两个明确给定依赖的关系模型。实验记录保留最近100条，存于当前浏览器并按原文哈希区分；清理浏览器数据可能删除记录，重要记录请导出。

## 本地AI与自己的材料

其他设备需要先安装Node.js 22.13+与Ollama，在项目目录运行：

```sh
npm run setup
npm start
```

CLI默认地址为 <http://127.0.0.1:4317>。首次模型下载约3.2 GB，模型权重不包含在源码包内。安装后不需要API密钥或付费服务。

Mac上可用 **Start-TraceLearn.command**。启动器先重建当前副本，再检查版本、安装目录哈希和构建指纹。遇到别的副本或旧构建时，不会误用或终止它，而是在4317–4336中选择空闲端口，终端会显示实际地址。已在两份独立快照上实测同时启动、重复复用和更新后启动新进程。

导入文本PDF、Markdown或TXT，最多10 MB、50页PDF；扫描件需先在外部OCR。选择原文面板中的任意片段，再点 **Generate from this passage**。程序选取未用过的合适句子，原文提供答案，Qwen提供干扰项；校验答案能否逐字还原句子。该片段用尽时会提示换片段，不会重复堆题。这是原文记忆练习，不是经过独立教师验证的概念迁移题。

**Ask the source** 使用真正的本地Qwen模型。引文能定位不等于解释一定正确，仍需核对推理。切换课程或取消请求后，旧请求不能覆盖新界面。

## 怎样理解评测

v1.2的 `npm test` 已通过48项自动化检查，包含单元测试和HTTP集成测试；不是48项纯单元测试。其中SQL内核与真实SQLite对照了1600个行结果，两个关系的全部24个属性子集与另一种独立实现的算法对照。这里的“独立”指计算方法不同，不是独立人工研究。

Evidence页保留原来的80条案例、两种方法共160次模型请求，以及错误、拒答、原始参考与AI辅助复核。可从“有依据的回答 / 材料外拒答 / 保留失败”三个入口开始，全部记录仍可逐条查询。这些是明确标记的历史输出，不是实时AI回答，也没有被改成新的高分结果。

没有真实学生研究、已验证提分、用户增长或获奖保证。Windows/Linux及直接双击HTML路径未实测；当前浏览器、构建和交付证据以 `../evidence/v1.2-acceptance.md` 为准。原v1.0、v1.1验收文件是历史记录，其中的草稿状态或旧测试数量不代表当前提交状态。
