## What was exercised

The test imported an original synthetic Markdown file with 7,171 characters. Import produced seven actual source passages. The seventh passage (`p3-7`, virtual page 3, **Selected passage seven**) contains exactly two eligible source sentences:

1. Ordinary comparisons involving a missing SQL value evaluate to UNKNOWN.

The HTTP client explicitly supplied `sectionId: "p3-7"` on each generation request. The first two calls returned different source-recall exercises. After both source sentences were used, a third call returned HTTP 409 with: “Every eligible sentence in this passage already has a practice question. Choose another passage or revisit an existing question.” The question list still contained exactly two saved questions.

- It then submitted that source-derived key to the real `/api/attempt` route. Both grades were correct and both responses returned `sourceIds: ["p3-7"]`.
- Both attempt responses and the reloaded SQLite history retained the original file SHA-256: `cf42dd8748735c4ecdfa0d72723272fa656e4a2da7ce16e7af02927d0c786bf0`.
- The imported course hash matched the SHA-256 of the actual uploaded file bytes. The planner did not replace the course hash with a sentence hash.
- The two distinct generated questions and two test attempt records persisted after reloading the HTTP question/history endpoints.

These were automated acceptance actions, not human learner observations or evidence of learning gains.
