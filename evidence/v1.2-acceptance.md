# TraceLearn v1.2 acceptance

Verified on 15 September 2026 on macOS, Apple M4 Pro, 24 GB memory. These are scripted software checks, not observations of student learning. This addendum supersedes the v1.1 feature surface, while retaining the frozen model experiment and its limitations.

## Changed experience

- Counterexample Lab accepts predictions before deterministic SQL truth / WHERE results and key closure / minimality traces. Editable values, operators and attribute selections clear the previous prediction and result.
- Real question feedback opens the relevant Lab; Lab returns to a fresh transfer attempt. The quick tour opens actual controls and never fills in a learner answer. Reopening its Experiment step resets the Lab to SQL even after switching internally to Keys.
- Notebook review hides earlier answers while retaining history. The sidebar reflects each question's latest grade. Imported exercises have unique labels and only the selected question is highlighted.
- Selected-passage generation works beyond the first five source segments, skips used statements and prevents concurrent duplicates. Exact-wording tasks explicitly distinguish wording differences from conceptual errors.
- Every frozen AI result remains visible in Evidence, with supported-answer, refusal and known-failure shortcuts.

## Reproducibility and remaining boundaries

Run `npm test`, `npm run build`, `npm run build:portable`, and `node --import tsx scripts/http-check.ts` after installing locked dependencies. The race fixture includes a repeatable browser procedure. The real generation procedure uses a separate test data directory; model output and timings may vary. Actual acceptance captures retain the hashes of the artifacts tested at that time; later copy, caption and quick-route corrections do not rewrite historical logs.

`content/course.ts`, `server/ai.ts` and all 13 evaluation files are byte-identical to v1.1.0. The original 160 model requests were not rerun or tuned against for this release. No new benchmark improvement is claimed.

Direct `file://` launch remains unverified because the browser automation tool blocks the scheme; no workaround was used. Portable interaction was verified via the README's local static preview. Its embedded-resource / connect-src none design is also checked by automated tests. Browser storage can be cleared, and embedded answer keys are for practice, not secure examinations. Lab history is browser-local in both editions and is exported separately from the full app's SQLite notebook.

The SQL interface supports four numeric/NULL predicates and nonempty bounded lists, not arbitrary SQL. The key interface uses two stated dependency systems. Source-recall distractors can be semantic paraphrases of the key; only literal reconstruction is graded. Citation existence does not prove correct reasoning. Windows/Linux, a general SQL engine, independent student outcomes and a contest ranking were not verified or claimed.
