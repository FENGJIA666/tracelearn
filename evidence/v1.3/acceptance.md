# Version 1.3 acceptance

The final r8 implementation and recorded comparison passed the scoped software acceptance below on Apple M4 Pro, 24 GB RAM and macOS. These are scripted checks by Codex, not a learner study or independent human audit. The immutable archive and public submission are verified afterward in the workspace publication receipt.

| Boundary | Observed evidence |
| --- | --- |
| Frozen evaluation | First 40-case holdout: current 34/40 strictly correct; previous 18/40. Development: 38/40 versus 20/40. Each split retains all 80 paired requests and saved judgments. One comparator ambiguity remains unresolved with no strict credit. |
| Automated boundaries | 123/123 final tests and the 11 isolated HTTP checks passed. The package guard separately passed 16 synthetic-fixture checks. These are distinct suites and are not model accuracy scores. |
| Actual browser | Ten Chrome checks covered current/old evidence, unchanged filter totals, each record's source, keyboard, 390px English/Chinese and portable practice, Lab, transfer, actual exports and refresh. Five in-app-browser checks covered a real current-model answer, source navigation, saved-answer recovery, export event/content and narrow layout. |
| Current local AI | Two controlled HTTP requests and one UI request returned the correct 100/FALSE, 200/TRUE, NULL/UNKNOWN explanation with exact source excerpts. Three saved chats survived refresh. All used the frozen r8 answer pipeline; no holdout was rerun. |
| Offline and recovery | App and Ollama ran under a localhost-only process policy. External hostname and literal-IP probes failed, while real answers succeeded. Cold was 25.791 s from an unloaded Ollama and fresh source-vector store; warm was 16.001 s. The allocation snapshot was 8.311 GB across the two models, not peak whole-system memory. Model unavailability returned 503 without a saved chat, and recovery succeeded. |
| Import/cloze and cancellation | The retained 12-check real fixture ran r7 and is labelled as such. Its three normal generations and delayed cancellation check are not presented as r8 end-to-end proof. Current deterministic import/cloze/cancellation boundaries are covered by final automated checks. |
| Long input | The r8 fixed-retrieval context test correctly returned two codes from five 1,400-character Chinese passages. A 24,031-token input was rejected against the 16,384-token limit. This is not a worst-case tokenizer or retrieval-quality benchmark. |
| Fresh installation | Actual npm ci installed locked dependencies without a symlink. The fresh runtime source and compiled assets matched the final app. The Mac launcher selected port 4318 while preserving the existing service; the isolated launcher and its child were then stopped. |
| Original user storage | The main application was restarted on 4317 as v1.3.0. Sorted contents and counts of courses, questions, attempts and chats were unchanged. Private records and the backup are excluded from public files. Ordinary local Ollama service was restored. |

The [acceptance JSON](acceptance.json) binds the underlying evidence by SHA-256. Read [final browser checks](ui/final-ui-checks.md), [real AI acceptance](ui/real-ai-acceptance.json), [offline exchanges](offline-check.json), [model recovery](model-recovery.json), [fresh installation](fresh-install-check.json), [held-out review](holdout-run/SEMANTIC-REVIEW.md) and [reproduction instructions](REPRODUCE.md) for scope and failures.

The browser and whole computer were not disconnected. Direct file:// automation remains blocked; portable practice was verified using static localhost HTTP. The in-app-browser export event and report endpoint content were checked, without inspecting that native download destination. Chrome portable downloads were inspected as actual files. Windows/Linux, universal injection resistance, broad semantic distractor quality, independent human assessment, grade gains and contest ranking remain unverified.

No new model, prompt, answer-pipeline or scoring-protocol changes followed the holdout. Failed development variants, all six current holdout failures, the unresolved source ambiguity and the original experiment remain available. The chosen version is the strongest configuration supported by this development and frozen-evaluation sequence, with its measured tradeoffs; it is not a claim of global optimality.
