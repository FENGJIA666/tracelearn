The initial pilot was stopped after a separate browser acceptance question produced an answer that only repeated the question despite valid quotes. Prompt v2 explicitly requires a finished answer and rejects exact question echoes and leading planning text. The frozen dataset is unchanged. Some pilot holdout requests ran, but their answer content was not used to tune v2. This is an internal development benchmark, not an independently blind study. The v2 run was also stopped after the second UI finding; both pilots are retained for transparency.
A second independent browser question exposed option-letter leakage in a non-MCQ answer. The final v3 system message now includes MCQ instructions only when explicit A/B options are present, rejects unsupported option-letter answers and requires substantive explanation for open questions. The final dataset remains unchanged. Both pilots are excluded from final denominators.
